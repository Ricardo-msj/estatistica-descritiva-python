# Estatística Descritiva com Python

Este repositório contém estudos de estatística descritiva aplicados à análise de dados,
utilizando Python, pandas e Jupyter Notebooks (Google Colab).

## Conteúdos abordados
- Frequência absoluta e relativa
- Análise de variáveis qualitativas
- Crosstab e renda média
- Classificação de renda em faixas socioeconômicas

Repositório criado para fins de aprendizado e portfólio.
